# PERSONA 8 — POST-PURCHASE (RUN 3)

Run 2: *can track.* Run 3: **can track and self-serve.**

TRACK ORDER holds its footer slot; TRACKING sits in the menu; and the FAQ now answers the
questions a waiting customer actually types — dispatch time, delivery window, "tracking says
delivered but I have nothing", returns process. The terms page backs it with LOST PARCELS and
FAULTS sections. This persona's run-1 dead end is now a three-surface path.

they email the address on the shipping policy, it bounces (`gmail.com.com`).
