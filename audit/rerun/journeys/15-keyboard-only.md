# 15 — Priya, keyboard-only shopper (no mouse, no touch — RSI), evening browse that turns into a proper test of whether this shop will let her buy at all
**Device:** Desktop 1440x900, keyboard only (Tab / Shift+Tab / Enter / Space / Escape / arrows) · **Goal:** Homepage → menu drawer open and closed → catalogue → a product → size → add to bag → cart page. KEY this run: the Getaway popup's keyboard behaviour, observe-only · **Mood:** Braced. Most fashion sites lose me at the first overlay.

### Step 1 — Landed on the homepage and pressed Tab
**Did:** Arrived, waited for the page to settle, started tabbing. / **Got:** First Tab went straight into the cookie banner: Privacy Policy link, then Manage preferences, Accept, Decline — Decline was my 4th Tab, with a clear visible ring on it. The banner is first in the tab order, before even the skip link. / **Expected:** To have to tab through half the page to reach the cookie buttons. / **Felt:** "Oh — the thing blocking me is the first thing I can reach. That's how it should work." / **Next:** Decline it.

### Step 2 — Fumbled the banner once, honestly
**Did:** On my first pass I was nosing around and tabbed PAST Decline to see the page (skip link, logo, SHOP, SEARCH, BAG, LIGHT MODE, MENU, then footer links). Then tried to get back to Decline by tabbing forward. / **Got:** Forty-plus presses later I was deep in the footer and the banner never came round again — I'd have needed Shift+Tab. Meanwhile, about 30 seconds in, the Getaway popup arrived over the still-open banner. / **Expected:** My own fault, mostly — but a "focus wraps back eventually" is a long punishment for overshooting four buttons. / **Felt:** "I've lost the banner. And now something else has taken over." / **Next:** Start fresh, decline properly: 4 Tabs, Enter. Done. And the moment I declined, the popup appeared — it had clearly been waiting politely for the banner. That, I rate.

### Step 3 — THE GETAWAY popup: where does my focus go? (KEY)
**Did:** Let the popup appear and checked where I was. / **Got:** Focus was MOVED for me — onto the popup's × close button, visible ring, top-right. From there Tab went: RUN IT → NOT NOW → back to × — a strict three-stop cycle, Shift+Tab reverses it, nothing behind the popup is reachable, page scroll locked, background aria-hidden. NOT NOW is 2 Tabs from the moment it opens. Escape closed it instantly. The only wobbles: the × floats alone in the far corner of the SCREEN, nowhere near the card in the middle, so the first ring I saw was oddly orphaned; and after Escape my focus was dumped to the top of the page (it tried to return me to the cookie Decline button, which no longer exists), so my next Tab started from the skip link again. / **Expected:** The usual nightmare: focus left behind the overlay, tabbing the whole page to find a close. / **Felt:** "Someone actually built this for me. Take focus, trap it, Escape works, NOT NOW two tabs away. I'm almost suspicious." / **Next:** It offered 10% off — "code sent by text", RUN IT / NOT NOW, "One code per player." I'll play it. By keyboard.

### Step 4 — RUN IT, into the game
**Did:** Tab to RUN IT, Enter. "OPENING THE LOCK-UP…" then a game screen loaded in a frame (~1.5s). / **Got:** A second, near-identical offer screen inside the game — "CRACK THE CUFFS." RUN IT / NOT NOW again, and only HERE does it say the code expires in 20 minutes and the drop closes 15.09. Tab took me INTO the frame: its Close, RUN IT, NOT NOW all focusable with visible rings. But two things: while focus sits on the frame itself there is NO visible ring anywhere (one blind press), and — important — ESCAPE STOPPED WORKING the moment my focus was inside the game. Pressed it dead on the game's RUN IT: nothing. The page can't hear me from in there. To leave I'd have to tab to one of the two × buttons. / **Expected:** Escape to work everywhere in the popup. / **Felt:** "There's a moment where my panic button is disconnected and nothing tells me." / **Next:** Play anyway. (First attempt, confession: I tabbed one stop too far, focus fell invisibly out of the frame, landed on the outer ×, and my Enter closed the whole game. Had to let it re-offer and start over.)

### Step 5 — Played and WON, keyboard only
**Did:** Enter on the game's RUN IT. Three tumblers appeared — each one is a real button ("TAP"), tab-reachable, and it says "No timer — take your time." Tab to each, Enter to lock: 1/3, 2/3, 3/3. / **Got:** "CUTTING THE CODE…" then an evidence tag: EVIDENCE Nº GTWY-U2SE, 10% off, one use, a live countdown "Expires in 19:57", a COPY CODE button, and a phone-number ask: "Phone number goes in the evidence log — one message per drop" with a UK phone field (07XXXXXXXXX), FILE IT, and "No need — I've got it". I did NOT give any number — audit rule. Enter on "No need — I've got it" worked: the phone ask folded away, code stayed. Also: the code arrived ON SCREEN — nobody sent any text, despite "code sent by text" on the first sheet. / **Expected:** A twitch-timing game I physically can't play. / **Felt:** "I won a discount with Enter. Genuinely — how often can I even PLAY these things?" / **Next:** Copy the code.

### Step 6 — COPY CODE, and the site grabbed the wheel
**Did:** Tab to COPY CODE, Enter. Button flipped to COPIED. / **Got:** About a second later, without any warning, the ENTIRE PAGE navigated itself — to crooksldn.com/collections/all. Not this shop's staging preview: the LIVE site, different-looking theme, prices in dollars, my focus dumped on the body of a page I never asked for. The popup, the countdown, my place — gone. (Harness note, out of character: the hand-off hard-codes the production domain, so from the preview it ejects you off the staging theme entirely; even in production, "copy" silently becoming "navigate" is a shock with no announcement for anyone not looking at the middle of the screen.) / **Expected:** Copy means copy. I stay where I am, I decide where to go. / **Felt:** "I pressed a COPY button and got teleported to a different shop. Worst moment of the night — I checked the address bar twice." / **Next:** Back to the actual errand, fresh eyes. One more popup note from re-visits: winning sets NO flag — on my very next homepage visit the popup offered itself again, ~3s in ("One code per player", but it will keep asking). NOT NOW, at least, snoozes it properly (14 days, verified). NOT NOW got me a focus-dump to top-of-page again, same as Escape.

### Step 7 — The menu drawer, done right
**Did:** From the homepage: 7 Tabs to MENU, Enter. / **Got:** Focus moved straight onto CLOSE. Tab cycled INSIDE the drawer only: SHOP, a "Show SHOP links" toggle, TRACKING, QUESTIONS, TERMS, CONTACT, the CASE 001 game card, ACCOUNT, BAG, CLOSE, and round again. Escape closed it and put my focus BACK ON THE MENU BUTTON — exactly where I left. / **Expected:** After the popup, I hoped. / **Felt:** "Textbook. Whoever built this drawer has used a keyboard." / **Next:** Shift+Tab back four stops to SHOP, Enter → catalogue.

### Step 8 — Catalogue by Tab
**Did:** Tabbed through /collections/all. / **Got:** Header (7), then the view/category filter buttons (FLAT, ON MODEL, ALL, T-SHIRT, DENIM, SWEATS, ACCESSORIES — all focusable, visible rings), then the 13 product cards, each ONE clean tab stop reading like "NO. 09 SWEATS GREY CONVICT SWEATS £60.00 2 OF 5 SIZES LEFT" — name, price, stock warning all in the link. My target was card 9, Tab number 23 from the top of the page. No skip-to-grid, but 23 presses for the 9th product is fair. The page scrolled along with my focus. / **Expected:** Cards split into three tab stops each (image, title, price) like most shops. / **Felt:** "One stop per product and it TELLS me only 2 sizes are left before I commit. I know things mouse users have to squint for." / **Next:** Enter on the Grey Convict Sweats.

### Step 9 — Size, then the button that wasn't there
**Did:** On the product page: Tab 8 was "← CATALOGUE", 9 an "Evidence photographs" tray, 10–11 photo thumbs, 12–16 the sizes XS S M L XL, 17 SIZE GUIDE. I tried arrow keys on the sizes first — nothing, they're toggle buttons, not radios. Tabbed to S, pressed Space: selected (highlighted, aria-pressed), sold-out M/L/XL sit struck-through but still take a Tab each. / **Got:** Here's the catch I fell into on my first pass: BEFORE you pick a size, ADD TO BAG is nowhere in the tab order at all. I tabbed past SIZE GUIDE expecting it, got accordions, related items, then the footer — and an over-eager Enter landed me on TRACK ORDER and a tracking page. Once a size IS selected, ADD TO BAG appears right after SIZE GUIDE, 5 Tabs on from S. / **Expected:** A disabled "pick a size" button I could still land on, telling me why I couldn't proceed. / **Felt:** "The button doesn't exist until I've guessed the missing step. A skipped stop explains nothing — I diagnosed it by falling into the footer." / **Next:** Enter on ADD TO BAG.

### Step 10 — Added, and into the cart
**Did:** Enter on ADD TO BAG. / **Got:** No drawer stole focus (fine by me) — but my focus also just… dissolved to the page body. Three Tabs later (shop-pay button — ring invisible on that one — then "More payment options") came "> Added — 1 in bag  View bag", and the header said BAG [1]. Enter on View bag → the cart page: GREY CONVICT SWEATS, Size S, £60.00, "£20.00 to free Tracked 24". Focus again starts from body on arrival, but everything on the cart page is reachable. / **Expected:** Some sites trap you in a cart drawer with no way out; this let me walk. / **Felt:** "Bag [1]. I did the whole thing — game included — without touching a mouse." / **Next:** Stop here per the rules; checkout button is reachable, and that's all I need to know tonight.

## Outcome
**Bought / didn't:** Didn't complete — by design (audit stops at the cart). But the cart was reached, keyboard-only, with Grey Convict Sweats S £60 in it. A keyboard-only shopper CAN buy here — that's a rare yes.
**Total time:** 19 minutes (about 6 of them on the popup and the game, 3 recovering from the COPY CODE ejection and my own overshoots).
**Worst moment:** Pressing COPY CODE and having the whole page navigate itself to crooksldn.com/collections/all — off the site I was on, prices in dollars, focus dumped, code screen gone. Runner-up: Escape going silently dead the moment focus is inside the game frame.
**Best moment:** The menu drawer's Escape putting focus back on the MENU button — and locking three tumblers with the Enter key to win 10% off. The popup itself takes focus, traps Tab in a 3-stop cycle, and puts NOT NOW two Tabs from arrival: no page-tabbing to refuse it.
**Would they come back?** Yes — this is the most keyboard-drivable independent shop I've used all year. I'd just wince every homepage visit until they honour the win flag, because the popup re-offers itself even after you've won a code.
**One thing that would have changed the outcome:** Nothing blocked the purchase — but make COPY CODE copy and stay put (no self-navigation), and the popup would go from "impressively accessible with one betrayal" to trustworthy end-to-end.
