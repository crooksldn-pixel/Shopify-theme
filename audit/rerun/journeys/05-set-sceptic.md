# 05 — Marcus, 31, worked retail for years, believes every "bundle" is a card trick until proven otherwise
**Device:** iPhone-size mobile (390×844), home wifi, Wednesday ~21:30 · **Goal:** wants the charcoal crewneck, has heard about the "full fit" set offer, and has "10CROOKS" saved from the brand's Instagram bio — came to work out whether £85 for the set is a real saving or the usual bundle mark-up shuffle · **Mood:** interested but arms folded

### Step 1 — Landed on the homepage, popup lands ON TOP of the cookie box
**Did:** Opened the site. Cookie consent banner sat at the bottom. Was reading the homepage when, about 30 seconds in, a full-screen takeover appeared: "CROOKSLDN: THE GETAWAY — Crack the cuffs. 10% off your first order — code sent by text. Attempts unlimited." with RUN IT / NOT NOW and "One code per player." in small print. (r05-01, r05-02)
**Got:** The popup physically covered the cookie banner — I literally could not press the cookie Accept button until I'd dealt with the game first. Closed it with the ×, then did cookies.
**Expected:** One interruption, not two stacked on top of each other.
**Felt:** "Hold on — 10% off for playing your game and handing over my phone number? I've already GOT a 10% code from your Instagram, for free. Not texting anyone. And sort your popups out, they're queueing on top of each other."
**Next:** Scroll the homepage for the crewneck.

### Step 2 — Read the catalogue cards like a till receipt
**Did:** Scrolled the homepage register. Found "NO. 01 SWEATS — CHARCOAL CELLBLOCK CREWNECK £50.00 AVAILABLE" and, right next to it, "NO. 02 — CHARCOAL CELLBLOCK SHORTS £45.00 AVAILABLE". Noted both prices down before touching anything. No "set" pricing anywhere at card level. (r05-03)
**Got:** My baseline: £50 + £45 = £95 for the two pieces. Now let's see what story the product page tells.
**Expected:** Exactly this — individual prices I can hold the bundle against.
**Felt:** "Good. Numbers first, marketing second."
**Next:** Open the crewneck.

### Step 3 — The set offer, read cold
**Did:** On the crewneck page (£50). Under the size grid: a small thumbnail of the shorts with a checkbox — "Cop the full fit — add the matching Cellblock Shorts. Save £10." Nothing else: no set total, no shorts price shown yet. (r05-04, r05-05)
**Got:** The claim, but not the arithmetic. It doesn't tell me the shorts price or the set price until I commit to ticking things.
**Expected:** The offer to show its working up front: "£95 → £85".
**Felt:** "'Save £10' off WHAT, though? That's the oldest move in the book — say the saving, hide the base. I'm checking the shorts price myself."
**Next:** Verify the shorts price on its own page.

### Step 4 — Cross-examined the shorts page
**Did:** Tapped through to Charcoal Cellblock Shorts via the "MORE FROM THIS DROP" row. Its page: £45.00, plain as day. Also noticed it runs the mirror-image offer — "add the matching Cellblock Crewneck. Save £10." (r05-07)
**Got:** Confirmation. £50 + £45 = £95. If the set is £85, the £10 is real — measured against the actual everyday prices, not an invented "was" number.
**Expected:** Honestly? I half expected the shorts to be £39 somewhere else on the site and the "saving" to be fiction. It isn't.
**Felt:** "Alright. So far the deck's clean."
**Next:** Back to the crewneck, run the set flow properly.

### Step 5 — Ticked the box and watched the numbers
**Did:** Back on the crewneck. Picked size M ("IN STOCK" appeared). Ticked the full-fit checkbox — a panel unfolded: a second size row for the shorts, picked M there too. Now it showed "~~£95~~ £85 for the set", "FREE UK TRACKED 24 INCLUDED", and the button became "ADD THE FULL FIT — £85". (r05-08, r05-09)
**Got:** The struck-through £95 matches my own arithmetic exactly. Two sizes chosen independently — crewneck M, shorts M — which is how it should work. One eyebrow raise: "FREE UK TRACKED 24 INCLUDED" is dressed up as a set perk, but the header says free shipping over £30 and the cart later showed Tracked 24 unlocks at £80 anyway — an £85 basket gets that regardless.
**Expected:** An inflated anchor price. Didn't get one.
**Felt:** "£95 struck through and that's genuinely what the pieces cost. Fine, I'm impressed. The 'free shipping included' line is padding though — you'd give me that on any £85 order."
**Next:** Add it, then see what my Instagram code does.

### Step 6 — Added the set; the bag count plays it loose
**Did:** Tapped ADD THE FULL FIT — £85. Header went to BAG [2]. Opened the cart. (r05-10, r05-11)
**Got:** One line: "CELLBLOCK SET — CHARCOAL CELLBLOCK CREWNECK - M / CHARCOAL CELLBLOCK SHORTS - M — £85.00". Estimated total £85.00. But the header says BAG [2] while the cart page badge says 1. Two garments, one line, pick a number.
**Expected:** The bag icon and the cart to agree with each other.
**Felt:** "£85, as advertised, both sizes right — good. But BAG [2] then 'Cart 1' makes me look twice. When a shop's counters disagree, I start recounting everything."
**Next:** Find somewhere to put 10CROOKS.

### Step 7 — Played the Instagram code in the cart
**Did:** Found a "Discount" accordion on the cart page, opened it, typed 10CROOKS, hit Apply. (r05-13, r05-14)
**Got:** Instantly: "10CROOKS −£8.50", estimated total £76.50. The code STACKS on the set price — 10% off the already-discounted £85. And the shipping bar still says "Free Tracked 24 — unlocked", though the total's now below the £80 tier — I'd want to see that hold at checkout. (r05-15)
**Expected:** The usual "this code cannot be used with this item" rejection. Bundles are normally excluded from codes.
**Felt:** "No exclusions? So it's £76.50 for £95 worth of clothes. Either someone's generous or someone hasn't done their margin maths — either way, that's my problem to enjoy, not fix."
**Next:** Check out and make sure the £76.50 sticks.

### Step 8 — Checkout quietly binned my code
**Did:** Tapped Check out. Landed on the checkout page and went straight for the order summary. (r05-16, r05-17)
**Got:** CELLBLOCK SET £85.00. Subtotal £85.00. Total £85.00. No 10CROOKS anywhere. The £8.50 the cart just promised me had silently evaporated between two screens.
**Expected:** The cart total to carry over. That's the whole contract of a cart.
**Felt:** "THERE it is. Knew there'd be a move somewhere. If I were the trusting type I'd have paid £8.50 over the odds without ever knowing. This is exactly the thing I came here suspecting — except it's the checkout plumbing, not the pricing."
**Next:** Re-enter the code at checkout and watch it like a hawk.

### Step 9 — Re-typed the code, got the right total, stopped
**Did:** Typed 10CROOKS into the checkout's own Discount code field, hit Apply. (r05-18, r05-19)
**Got:** "Order discount 10CROOKS −£8.50", Total £76.50, and a "TOTAL SAVINGS £8.50" tag. Stopped there — nothing entered, no order placed.
**Expected:** £76.50 — which is what I got, second time of asking.
**Felt:** "Funny thing: their own checkout says I saved £8.50, but against buying both pieces separately at full whack I'm £18.50 up. The one place they undersell is their own generosity. The set story is legit; the pipework between cart and checkout is what needs arresting."
**Next:** Done. Would place this order in real life.

## Outcome
**Bought / didn't:** Didn't (audit stop at checkout) — but the sceptic was won over: he'd have bought the set at £76.50. · **Total time:** ~12 minutes, a third of it spent double-checking prices the site could have shown up front. · **Worst moment:** Checkout landing showing £85 with the cart's 10CROOKS discount silently gone — the exact "card trick" he came looking for, found in the plumbing rather than the pricing. · **Best moment:** The set panel revealing "~~£95~~ £85 for the set" and the strikethrough matching his own independently-verified arithmetic (£50 + £45) to the penny — no inflated anchor. · **Would they come back?** Yes — the pricing survived a hostile audit, and the code stacking (£76.50 for £95 of clothes) reads as generous, not shady. He'd still re-check every total at checkout forever. · **One thing that would have changed the outcome:** Carry the cart-applied discount code through to checkout (or at least warn it needs re-entering) — a less suspicious shopper pays £8.50 more and never knows.

### Sceptic's ledger (the actual arithmetic)
- Crewneck alone: £50.00 (own PDP) · Shorts alone: £45.00 (own PDP) · Sum: £95.00
- Set: £85.00 — shown as ~~£95~~ £85; saving real, base prices honest
- 10CROOKS in cart: −£8.50 → £76.50 (stacks with the set; no exclusion)
- Checkout landing: £85.00, code dropped; re-entered → £76.50, "TOTAL SAVINGS £8.50"
- vs buying separately with the code: £95 × 0.9 = £85.50 → the set stays £9.00 cheaper even code-vs-code
- Open question: at £76.50 (below the £80 tier) the cart still claimed "Free Tracked 24 — unlocked"; not verified past the address step
