# 11 — Marcus, 27, product designer who pokes every switch before he trusts a site
**Device:** iPhone 390×844 first, then a 1440×900 laptop pass · **Goal:** back to see whether the police-terminal gimmick still holds up — and whether they fixed the switches; jeans if they did · **Mood:** Wednesday evening, tea gone cold, notebook out

### Step 1 — Arrived, met the cookie slab, pressed Decline twice
**Did:** Opened the site on my phone. Big dark cookie banner across the bottom third. Tapped Decline.
**Got:** Nothing — the button lit up with a focus ring and just sat there. Tapped it again; banner gone. (r11-01, r11-02)
**Expected:** One tap, one dismissal.
**Felt:** A button that takes the press but not the meaning. Probably me, possibly it. Either way I noticed.
**Next:** continued — and the site wasn't done with me

### Step 2 — The Getaway popup, one breath after the banner
**Did:** Barely a second after the cookies went, a full-screen popup: "CROOKSLDN: THE GETAWAY — Crack the cuffs. 10% off your first order — code sent by text. Attempts unlimited." RUN IT / NOT NOW, "One code per player." (r11-03)
**Got:** A challenge, styled like the rest of the terminal.
**Expected:** The usual email-for-10% modal.
**Felt:** "Code sent by text" — hmm. That's the phone-number toll flagged in advance, at least. Still, the game is the one popup I'll ever press.
**Next:** continued — RUN IT

### Step 3 — Ran it, hit the second gate, played the tumblers
**Did:** Pressed RUN IT. Got… another cover screen, this one headed "CRACK THE CUFFS." — old name, apparently — with its own RUN IT and small print: one code per player, unlimited attempts, code expires in 20 minutes, "(this drop closes 15.09)". Pressed RUN IT again. Three tumbler digits, "TAP TO STOP", a timer bar, 0/3 LOCKED. Tapped all three. (r11-04, r11-05)
**Got:** Locked all three. The game itself sits in the bottom third of the screen with a sea of empty black above it — my thumb liked it, my eyes kept wondering what the rest of the screen was for.
**Expected:** To lose at least once, honestly.
**Felt:** The double gate is clumsy — GETAWAY on the outside, CUFFS on the inside, two RUN ITs before anything runs. But the game is still fun.
**Next:** continued — braced for the phone-number ransom

### Step 4 — Won, and the code just… appeared
**Did:** Read the result screen.
**Got:** An evidence tag: "EVIDENCE Nº GTWY-VEEV — 10% off. One use. Expires in 19:58", a big COPY CODE button — and below the fold, the phone ask, now optional: "Want it kept on file? Phone number goes in the evidence log — one message per drop, nothing else. Same promise as the register. FILE IT" and an honest opt-out: "No need — I've got it." (r11-06)
**Expected:** The cuffs to go on ME — win the game, surrender the number, like these things always do.
**Felt:** Genuinely surprised. The prize is the prize; the number is a polite afterthought with the plainest consent copy I've seen on a shop. One catch: the cover screen said "code sent by text" and that's simply not what happens any more — the code lands on screen. The pitch is scarier than the product. Also noted the panel wanted a phone number I was never going to give it.
**Next:** copied the code in my head, tapped "No need — I've got it", closed the popup

### Step 5 — Found the register controls; the OUTLINE switch is gone
**Did:** Scrolled to the CATALOGUE (13 items). Control row: FLAT / ON MODEL, then ALL / DENIM / SWEATS / T-SHIRT / ACCESSORIES. (r11-07, r11-08)
**Got:** Two rows of chips — and no OUTLINE button anywhere. The evidence-sticker halo around every flat garment is just… there, on by default, not a setting.
**Expected:** The full switchboard from what I'd heard: view mode AND an image-treatment toggle.
**Felt:** Someone made a call, and it was the right one. The look stays, the dead switch goes. Small gripe: the category row scrolls sideways and "T-SHIRT" arrives half-clipped at the screen edge — I only found ACCESSORIES because I'm the kind of person who pulls at edges.
**Next:** continued — flipped the switch that's left

### Step 6 — ON MODEL: the clone army is still enlisted
**Did:** Tapped ON MODEL, scrolled the whole catalogue.
**Got:** Every card — crewneck, shorts, socks, duffle bag, all 13 — became the SAME photo: one man in a black tee and grey shorts on a little glass pedestal. The crewneck card: him, not in a crewneck. The socks: him, socks invisible. (r11-09, r11-10, r11-11)
**Expected:** After everything else got fixed, real on-body photos.
**Felt:** Same laugh as ever, still not kind. A view mode that replaces the product with a stock man is worse than no view mode — it un-sells things. And the punchline came later on the jeans page: photo 2 of 2 there IS a real person wearing the jeans. The photography exists. The toggle just doesn't use it.
**Next:** tapped straight back to FLAT, went hunting for the light switch

### Step 7 — Hunted the light switch into the drawer
**Did:** Looked at the header: SHOP, search, BAG, MENU. No LIGHT MODE up top on mobile any more. Opened MENU.
**Got:** The drawer: SHOP, TRACKING, QUESTIONS, TERMS, CONTACT — then a little animated pixel-art jail map (a thief creeping about, coins, patrolling officers) with a big purple PLAY CROOKS: THE GETAWAY button, and at the very bottom edge of the screen, the row I wanted: LIGHT MODE · ACCOUNT · BAG. (r11-12, r11-16)
**Felt:** The switch has moved house — off the header, into the basement of the menu, below a promo for the game I've already beaten. It's findable, but it's the last thing the drawer offers, right at the bottom lip of the screen. (In this staging preview, Shopify's own preview bar sat exactly on top of it, which made pressing it a fight — a real phone wouldn't have that bar, but parking the site's only theme control on the screen's last 60 pixels is still a choice.)
**Expected:** LIGHT MODE in the header where a label that good deserves to live.
**Next:** pressed it

### Step 8 — Light mode: still the best trick, now with adaptive halos
**Did:** Flipped LIGHT MODE, closed the drawer, rescrolled the catalogue.
**Got:** The photocopied-case-file look — off-white, scanlines, everything readable. And the flat garments now sit in a soft lavender glow instead of the cream sticker edge: the outline treatment quietly re-tuned per theme, no button required. Curious detail: the drawer itself stays black in light mode — a dark pocket in a light site. (r11-17, r11-19, r11-23)
**Expected:** Light mode to still be good; I wasn't expecting the halo to follow the theme by itself.
**Felt:** This is exactly what the old OUTLINE button should have been all along — a design decision, not a dial. Verdict written for me.
**Next:** continued — checked whether the site remembers any of this

### Step 9 — Memory test: the theme half-remembers, the popup never forgets
**Did:** With light mode on, opened a product page, then reloaded it. Later, closed everything and came back fresh.
**Got:** Within the visit: light mode sticks across pages and a reload. Fresh visit: back to dark — the choice lives in session storage and dies with the tab. And the popup? I closed it with its own ×, code already claimed — next page-load, the full-screen GETAWAY cover jumped me again inside a second, still promising a "code sent by text", still saying "one code per player" to a player who has one. While it loads it also lays an invisible full-screen cover over the page — one of my taps went into it and just vanished. (r11-22, r11-40)
**Expected:** Dismissed means dismissed; chosen means chosen.
**Felt:** They fixed what the game asks of you and forgot to teach it manners. Every visit starts with the same stick-up. That's how you make people resent a thing they liked.
**Next:** continued — to the jeans, and the toggle I actually respect

### Step 10 — MEASUREMENTS: the numbers grew up, the memory didn't
**Did:** Opened BLUE WASH YARD JEANS (£60). Accordions: CHAIN OF CUSTODY — SHIPPING & RETURNS, SPECIFICATION, ITEM DESCRIPTION, MEASUREMENTS. Opened MEASUREMENTS, then flipped CM → IN and checked the maths like the pedant I am.
**Got:** "TRUE TO SIZE. THESE ARE THE GARMENT'S OWN FULL MEASUREMENTS." — real circumference numbers now, not laid-flat: XS waist 76.2cm, M 86.4cm. Flip to IN: 30in / 34in. 76.2 ÷ 2.54 = 30.0 exactly. Caption stays honest in both units. (r11-26, r11-27) Two wrinkles: those centimetres are suspiciously round in inches — 76.2, 81.3, 86.4 are 30, 32, 34 × 2.54, so the table thinks in inches and translates — and my IN choice evaporated on the next product: the baggies opened back in CM. (r11-28)
**Expected:** The old laid-flat table.
**Felt:** True-to-size full measurements is the more useful convention and saying the method out loud is exactly right. Still the best control on the site. Still amnesiac between pages.
**Next:** continued — the sweatshirt test

### Step 11 — The crewneck has a table now

### Step 12 — Desktop pass: same site, bigger stage, switch back in the header
**Did:** Opened it on the laptop (fresh visitor: cookie banner, popup again — closed both). Ran the circuit: header, chips, ON MODEL, light mode, hover.
**Got:** LIGHT MODE sits visibly in the desktop header, and after flipping it the label reads DARK MODE — it tells you what you'll get, both directions. Chips identical to mobile, no OUTLINE here either. ON MODEL at four columns is the clone army in parade formation — four identical men labelled crewneck, shorts, jeans, jorts. (r11-32) Light catalogue at 1440px is properly handsome — purple-halo garments on scanned paper. (r11-34) Hover on cards: cursor change and nothing else.
**Expected:** Consistency, which is what I got — fixes and bugs alike.
**Felt:** The site is one coherent thing at any size. I just wish the one broken switch weren't quite so proud of itself in four columns.
**Next:** continued — right, buying

### Step 13 — Bought the jeans AND the crewneck, and the game paid for the socks I didn't buy
**Did:** Jeans page, tapped M — URL picked up the variant, which I clocked approvingly. ADD TO BAG → BAG [1]. Crewneck in L → BAG [2]. Cart: both items, £110, "Free Tracked 24 — unlocked" with the progress bar maxed, a quiet upsell ("Complete the set — add the Cellblock Shorts, save £10."). Check out → clean checkout, express pays up top. Typed GTWY-VEEV into the discount box. (r11-35 … r11-38)
**Got:** The tag applied instantly: Order discount −£11.00, total £99.00, "TOTAL SAVINGS £11.00". The game's code is real money. Stopped there — card stays holstered, per the rules of tonight. (r11-39)
**Expected:** Half-expected the code to be theatre.
**Felt:** Twenty seconds of tumbler-tapping earned me £11 and no one texted me anything. That's the whole popup contract, honoured. The buying spine remains the tightest part of the site.
**Next:** done

## Outcome
**Bought / didn't:** Bought — reached the checkout with BLUE WASH YARD JEANS (M, £60) + CHARCOAL CELLBLOCK CREWNECK (L, £50), Getaway code GTWY-VEEV applied, £110 → £99. Stopped at the payment step by audit rule. The crewneck is in the bag *because* it now has a measurements table — last time that was a one-item order.
**Total time:** ~30 minutes (a normal shopper does it in 10; I flip everything twice on two devices).
**Worst moment:** Tapping ON MODEL and watching thirteen products become the same man on a pedestal — again — while the jeans PDP quietly proves they own real on-model photography.
**Best moment:** Winning the tumbler game and the code just appearing on screen — then actually knocking £11 off at the till. Honourable mention: the outline halo re-tinting itself per theme with no button asked to exist.
**Would they come back?** Yes — the controls that remain mostly do what they say, and the game now pays out instead of taking hostages. But I'll be closing that popup every single visit, and I know it.
**One thing that would have changed the outcome:** Nothing stopped the purchase — but pull ON MODEL until each card has its real photo; it's the last switch on the site that lies.

### Control verdicts (the O3 evidence, run 2)
- **OUTLINE toggle — RETIRED, and rightly.** The control is gone from the register; the treatment survived as a default that adapts per theme (cream sticker-edge in dark, soft purple glow in light — verified in both). Nothing a shopper could want was lost; the dead-button and cross-theme-desync traps died with it. Correct call, cleanly executed. Verdict: keep it gone.
- **LIGHT/DARK toggle — KEEP, but move it back upstairs on mobile.** Desktop header placement with the label flipping LIGHT MODE ↔ DARK MODE is exemplary. On a phone it now lives at the very bottom of the menu drawer, under an animated game promo — findable by a tinkerer, invisible to a normal person. Choice persists across pages and reloads but resets on the next visit (session-only); remembering it would cost nothing.
- **FLAT/ON MODEL toggle — still HIDE until the photos are wired up.** Unchanged from run 1: every card shows one identical placeholder man wearing none of the products, mobile and desktop. Aggravating twist: real on-model shots exist on at least the jeans PDP — the catalogue toggle just doesn't use them.
- **CM/IN toggle — KEEP; now the best version of itself.** True-to-size full-garment measurements with the method stated, on every garment I checked (crewneck included, at last), conversion mathematically exact both ways. Remaining wish, same as last time: remember my unit across pages — it forgot IN between the jeans and the baggies.
