# 19 — Marcus, 34, back on his laptop on the sofa, second look at CROOKSLDN
**Device:** Desktop 1440x900, fast home broadband · **Goal:** No mission — free Wednesday evening, wants a proper look around and maybe a treat · **Mood:** Relaxed, unhurried, mouse in one hand, tea in the other

### Step 1 — Opened the site and actually got a homepage this time
**Did:** Loaded the homepage and started reading.
**Got:** A dark terminal-style homepage, straight away — no dimmed screen, no instant ambush. Ticker up top ("FREE UK SHIPPING OVER £30 // ORDER BY 18:00 FOR SAME-DAY DISPATCH"), a status line "> 13 PRODUCTS AVAILABLE TO PURCHASE", the CROOKSLDN title, OWN THE STREETS™, a CATALOGUE button — all parked on the left. A big cookie banner along the bottom, which I declined (r19-02-popup-settled.png, r19-16-hero-staging.png).
**Expected:** Last impressions of these brand sites are usually a popup before anything else.
**Felt:** Better welcome than most. Two quibbles: the whole right two-thirds of the hero band is empty black — the title hugs the left like the other half of the design didn't load — and the hero is so short it's more of a letterhead than a hero. Below it, though, a new "WORLD OF CROOKS" photo strip — five numbered "FRAME 01/05" shots of actual people in actual streets. Proper. Frame 05 is chopped off at the screen edge and I had to fiddle-scroll sideways to see it.
**Next:** continued

### Step 2 — Thirty seconds in, the game took the screen
**Did:** Was idly scrolling the grid when the whole page dimmed and a centred card appeared: "CROOKSLDN: THE GETAWAY — Crack the cuffs. 10% off your first order — code sent by text. Attempts unlimited." RUN IT / NOT NOW / "One code per player." (r19-03-popup-check.png)
**Got:** A popup that — credit where due — tells you the prize BEFORE you play: 10%, unlimited attempts. But "code sent by text" made me groan: here comes the phone-number harvest. The card itself is a tall dark rectangle with the content floating in the middle and acres of empty space above and below, and there's a lone × way up in the top-right of the SCREEN, nowhere near the card. There's a second, smaller × on the card itself later. Pick one.
**Expected:** Either a discount or a data grab; the copy at least was upfront.
**Felt:** Interrupted — I was reading the grid — but 10% is 10%, and "attempts unlimited" is charming. "Code sent by text" nearly made me close it on principle. Curiosity won.
**Next:** clicked RUN IT

### Step 3 — Pressed RUN IT and was asked… to press RUN IT again
**Did:** Clicked RUN IT. Got a SECOND intro screen: "CRACK THE CUFFS. 10% off your first order if you do. Three tumblers. Click each one at the right moment." with another RUN IT, another NOT NOW, "Code expires in 20 minutes" and "(this drop closes 15.09)" (r19-07-game-2.png). Clicked RUN IT again.
**Got:** The actual game: three digit tumblers spinning, "CLICK TO STOP", a draining bar, "0/3 LOCKED — Click each tumbler before the bar drains" (r19-11-tumblers.png). I clicked all three in time — first go — then "CUTTING THE CODE…".
**Expected:** One RUN IT, then the game.
**Felt:** Why am I consenting twice? Small thing, but it's a double door. The wording finally says "Click" for us mouse people — except the tumbler buttons themselves are each labelled "TAP", so the game can't quite decide what I'm holding. "(this drop closes 15.09)" — is that a date? A time? For one blink after the cut, the screen flashed "CODE EXPIRED" before the countdown appeared, and my heart skipped — cheers for that.
**Next:** continued

### Step 4 — Won a code, on my screen, no phone number needed — then COPY CODE teleported me off the site
**Did:** The win screen: "EVIDENCE Nº GTWY-VPZK — 10% off. One use. Expires in 19:57", a big COPY CODE button, and below it — optional — "Want it kept on file? Phone number goes in the evidence log — one message per drop, nothing else. Same promise as the register." with FILE IT and a clear "No need — I've got it" (r19-12-win-or-state.png). I clicked COPY CODE.
**Got:** The entire website vanished. One second I'm on the dark CROOKSLDN terminal, the next I'm on a WHITE site — same handcuffs logo, different everything: plain fonts, "13 items", prices in DOLLARS — $70 crewnecks (r19-16-hero-clean.png shows where I landed: crooksldn.com/collections/all). No warning, same tab. I sat there for a solid few seconds wondering if I'd been hijacked, then hit Back and the dark site returned. My code survived in my head because I'd read it off the evidence tag, not because the button helped me.
**Expected:** COPY CODE copies the code. That's the entire job description.
**Felt:** Genuinely rattled, then annoyed. The win screen is the best thing they've built — prize on screen, phone number OPTIONAL, honest copy about what the number's for, a polite no-thanks link — and then the main button on it launches you off the site to some other version of the shop with American prices. If I hadn't memorised the code I'd have lost it and my 20 minutes would already be ticking.
**Next:** went back (browser Back), carried on — warily

### Step 5 — Proper homepage wander: the grid has come alive, mostly

**Got:** The header responds now — SHOP, BAG, LIGHT MODE, MENU all get a purple outline under the mouse. About half the product cards swap to a second photo on hover (the shorts flip from front to back view with a purple border — r19-45-swap-before.png / r19-46-swap-hover.png); the other half sit there doing nothing. All 13 cells have product in them — no missing-shelf gaps like last time — BUT the last row is one lone pink card and then a wide flat purple slab of nothing stretching across three columns (r19-19e-grid-tail.png). The "EVERY ORDER SHIPS LIKE THIS" packaging section is still lovely. Then "REGISTER AS INFORMANT — New drops go live to the list first. Get on it." — and once again NO field, NO button, nothing to click (r19-20-register.png). I moved my mouse over the whole box hunting for a hidden input. Again. Nothing. Again.
**Expected:** Hover life (finally got some), a signup box you can sign up to (still can't).
**Felt:** The hover work makes it feel like a real desktop site at last — the half of the cards that flip are a proper little delight. Which makes the dead half feel broken rather than minimal. And "Get on it." with no way to get on it is now beyond parody — that's two audits running I've been ordered to join a list that has no door.
**Next:** continued

## Outcome
**Bought / didn't:** Bought (checkout intent) — the Cellblock set in L, £85 down to £76.50 with the game code. The set checkbox sold it; the working discount sealed it.
**Total time:** ~35 minutes, most of them enjoyable, two of them thinking I'd been hijacked.
**Worst moment:** Clicking COPY CODE on the game's win screen and being thrown off the site entirely — same tab, no warning — onto a white, dollar-priced version of the shop (crooksldn.com/collections/all). The best screen in the whole experience has a self-destruct button where "copy" should be. Runner-up: my code expiring and the cart rejecting it in total silence.
**Best moment:** The win screen itself — the code ON MY SCREEN, phone number strictly optional with honest copy about what it's for, and a fresh code knocking £8.50 off an already-discounted set. Last time I refused to hand over my number and left the game empty-handed; this time desktop players are first-class citizens of the heist.
**Would they come back?** Yes — the brand is fun, the set is good value, the site finally answers the mouse and answers the add-to-bag click. But it still treats bits of desktop as an afterthought: one-photo product pages with no zoom and no sticky buy bar, a placebo ON MODEL toggle, a signup box with no input, and a copy button that deports you.
**One thing that would have changed the outcome:** Nothing stopped the purchase — but make COPY CODE just copy (and make an expired code SAY it's expired) and you remove both moments where I nearly walked. And for the love of denim: more than one photograph of £60 jeans.
